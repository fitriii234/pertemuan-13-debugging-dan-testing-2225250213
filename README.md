Materi disusun berdasarkan bahan ajar:
- Pertemuan 13: debugging, tracing, testing, test case, dan praktik investigasi bug.
- Pertemuan 14: rancangan proyek program sederhana dan implementasi contoh Program Rekap dan Analisis Nilai Kelas.

## Cara mulai
1. Ekstrak ZIP.
2. Buka folder hasil ekstrak di VS Code.
3. Pilih interpreter Python 3.
4. Jalankan file `.py` yang diinginkan melalui tombol Run atau terminal.

## Pertemuan 13
Contoh:
```bash
python pertemuan_13/latihan/01_trace_loop.py
python pertemuan_13/praktik/praktik_4_debugging.py
```
